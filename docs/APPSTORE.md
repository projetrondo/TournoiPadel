## Confidentialité de l'app (App Store Connect → Confidentialité de l'app)

- « Collectez-vous des données à partir de cette app ? » → **Non, nous ne collectons pas de données à partir de cette app.**
- Résultat affiché sur la fiche : « Aucune donnée collectée ».

Cette version n'a ni partage en ligne ni compte : rien ne quitte l'iPhone. Le manifeste de confidentialité de l'app (`PrivacyInfo.xcprivacy`) le déclare aussi. Si le partage ou les comptes sont activés plus tard, il faudra mettre à jour ces réponses, le manifeste et la politique de confidentialité (voir `docs/COMPTES.md`).

## Informations pour la vérification (App Review)

- Connexion requise : **non** (décocher « Connexion requise »).
- Coordonnées : ton nom, ton téléphone et ton e-mail. Ils ne sont visibles que par Apple.

## Captures d'écran

- **Format exigé : iPhone 6,9 pouces** (1320 × 2868). L'atelier GitHub « Captures App Store » les produit, en français et en anglais, sur la branche `store-screenshots` (dossiers `fr/` et `en/`).
- Dans App Store Connect, déposer les 6 images de `fr/` pour la langue Français et celles de `en/` pour English (rubrique « iPhone 6,9 pouces »). Apple réduit lui-même les images pour les autres tailles d'iPhone.

## Étapes dans App Store Connect, dans l'ordre

1. **Mettre en ligne la version 1.0.0** : GitHub → Actions → TestFlight → Run workflow (champ `api_url` vide). Le build est numéroté automatiquement.
2. https://appstoreconnect.apple.com → **Apps → TournoisPadel**.
3. **Informations sur l'app** (menu de gauche) :
   - Nom : `EAGLE Padel` ; sous-titre ; catégorie Sports ; URL de confidentialité.
   - Ajouter la langue **Anglais (Royaume-Uni)** ou **Anglais (États-Unis)** avec le menu de langue en haut à droite, puis remplir nom, sous-titre et URL en anglais.
4. **Tarifs et disponibilité** : gratuit, tous les pays.
5. **Confidentialité de l'app** : « Aucune donnée collectée » (voir plus haut), puis **Publier**.
6. **Classification par âge** : répondre « Aucun » partout → 4+.
7. Colonne de gauche, **iOS App → 1.0 Préparer la soumission** :
   - captures (6,9 pouces), texte promotionnel, description, mots-clés, URL d'assistance, pour chaque langue ;
   - **Build** : « + » → choisir le build 1.0.0 envoyé par TestFlight ;
   - **Informations pour la vérification** : voir plus haut ;
   - **Publication de la version** : « Publier manuellement » (tu choisis le jour) ou « Automatiquement ».
8. **Ajouter pour vérification** → **Soumettre à la vérification**. Comptez en général 24 à 48 h. En cas de question d'Apple, la réponse arrive dans App Store Connect et par e-mail.

## Points déjà réglés dans l'app

- Partage entre iPhone et comptes **masqués** tant qu'ils ne sont pas activés : aucune fonction « bientôt disponible » visible, ce qu'Apple refuse souvent (règle 2.1).
- Chiffrement : `ITSAppUsesNonExemptEncryption = NO` (rien à déclarer pour l'export).
- Politique de confidentialité et assistance accessibles depuis l'app : Réglages → Comment ça marche ?
- Icône 1024 px sans transparence, iPhone uniquement, portrait.
